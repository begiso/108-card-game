# 108 — карточная игра

Многопользовательская веб-игра для компании из 2–6 человек. Задача — набрать меньше всех очков и не перевалить за 108.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm run dev        # то же, но с перезапуском при изменениях
npm test           # тесты правил + 300 партий ботов
```

Переменные окружения: `PORT` (по умолчанию 3000), `BOT_DELAY_MS` — фиксированная задержка хода бота (удобно для тестов).

## Как играть

1. Введите имя → «Создать комнату» (выберите число мест).
2. «Пригласить друзей» — скопируется ссылка вида `/?room=A82F`, или просто продиктуйте код.
3. Пустые места можно заполнить ботами. Создатель комнаты нажимает «Начать игру».

## Структура

```
server/
  index.js          HTTP (статика) + WebSocket /ws
  rooms.js          комнаты, хост, боты/автопилот, reconnect
  game/constants.js колода, стоимость карт, статусы
  game/engine.js    все правила: ход, 6/7/8/Q/A/K♠, добор, подсчёт, 107/108, выбывание
  game/bot.js       автопилот (боты и вышедшие игроки)
public/
  index.html, css/style.css
  js/net.js         соединение с автопереподключением
  js/app.js         отрисовка экранов и отправка действий
test/engine.test.js
```

## Принципы

- **Вся логика на сервере.** Клиент отправляет только намерение (`PLAY_CARD`, `DRAW_CARD`, `TAKE_PENALTY`, `PASS`), сервер проверяет ход, карту и эффекты и рассылает каждому своё состояние. Чужие карты клиенту не передаются.
- **Защита от двойного хода** — каждое действие несёт `version` состояния; устаревшее отклоняется.
- **Reconnect** — игрок опознаётся по `playerId` в localStorage; после перезагрузки страницы он возвращается в свою комнату.
- **Выход / потеря связи** — вышедший игрок сразу переходит на автопилот; при потере связи автопилот ходит через 30 секунд ожидания. Вернуться можно по коду комнаты.

## Протокол (WebSocket)

Клиент → сервер: `{ action, ... }`

| action | параметры |
|---|---|
| `HELLO` | `playerId` |
| `CREATE_ROOM` | `name`, `maxPlayers` |
| `JOIN_ROOM` | `name`, `code` |
| `LEAVE_ROOM`, `ADD_BOT`, `START_GAME`, `NEXT_ROUND`, `PLAY_AGAIN`, `BACK_TO_LOBBY` | — |
| `REMOVE_PLAYER` | `playerId` |
| `SET_MAX_PLAYERS` | `maxPlayers` |
| `PLAY_CARD` | `cardId` (напр. `8_hearts`), `suit` (для дамы), `version` |
| `DRAW_CARD`, `TAKE_PENALTY`, `PASS` | `version` |

Сервер → клиент: `STATE` (комната + персональное состояние игры), `ERROR`, `NO_ROOM`, `LEFT_ROOM`.

## Telegram Mini App

Скрипт `telegram-web-app.js` уже подключён: внутри Telegram имя подставляется из профиля, код комнаты берётся из `start_param`, используется вибрация. Для запуска в Telegram нужно выложить сервер на HTTPS-домен и указать его боту через @BotFather.
